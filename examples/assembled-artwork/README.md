# Assembled artwork examples

`truchet-recipe.json` is a job template consumed by the layout exporter; its empty
source domains are populated from a resolved layout before producer generation.
All dimensions in the recipe are SVG design units (96/25.4 units per millimeter
for exported resolved layouts).

`illustrative-folded-outer.json` is an explicit provisional four-panel example for
a 100 mm Cootie Catcher square, including one reflected assembled panel. It is not a
physically verified folded arrangement and is never an automatic default.

See [the handoff guide](../../docs/how-to/assembled-artwork-handoff.md) for export,
generation, return adaptation, partial bindings and software validation.

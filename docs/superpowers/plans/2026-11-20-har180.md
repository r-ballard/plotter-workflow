packing were implemented inline. The crossing-stroke test exposed bounds checks
reading unclipped SVG paths; validation now uses converter-equivalent polygon
materialization. Shared native helpers were moved without changing J-card
behavior. Blank-source viewport checks execute outside fragment iteration.

32/64/96 panel copies, unique IDs and references, tab bounds with guides off,
sheet spillover, explicit catalog mapping/collision rejection, retained-work
budget rejection, width mismatch, protected sources and committed regeneration.
Full repository suite: 834 passed. Changed-file Ruff and whitespace checks pass.
Independent read-only review found no actionable findings.

Three retained real jobs at the ticket's widths passed HP-GL conversion and
pen-plan/placement/tool-documentation preflight, with 5 mm margins and no send.
The three-copy output was rendered and inspected. Source generation hit three
Windows WinError 5 publication failures across worktree/shared output roots
(including an explicit overwrite retry). A fresh temporary artifact root
generated the complete pack successfully; the result was copied to
`output/hardware-acceptance/har180-letter-packing/` in the original checkout.
This is an environment limitation, not a claimed publisher fix. Original
failed attempts are not superseded as evidence by the successful alternate root.
